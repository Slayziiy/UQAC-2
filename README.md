# 8WEB101 : Projet libre
## Auteurs
- Laure GOLAZ
- Tom MAETIE
## Technologies
  - Java 17 Springboot ([spring.io](https://spring.io/))
  - Three.js ([threejs.org](https://threejs.org))
  - GSap ([gsap.com](https://gsap.com))
  - Tailwind ([tailwindcss.com](https://tailwindcss.com))
## Description
>  Le site web se présentera sous la forme d’un aquarium dans lequel les utilisateurs pourront ajouter des poissons qui nagent dedans. Pour se faire, les visiteurs du site pourront dessiner les motifs du poisson dans une zone prévue à cet effet et les poissons s’ajouteront.
